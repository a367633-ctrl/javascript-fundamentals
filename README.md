# Actividad 2. JavaScript y paradigmas

**Desarrollo Basado en Plataformas - Universidad Autónoma de Chihuahua**
**Autor:** Carlos Ubaldo Domínguez Valles (a367633@uach.mx)

Este repositorio contiene los ejemplos desarrollados durante clase para la Actividad 2, orientados a comprender los fundamentos de JavaScript y sus principales paradigmas de programación (Funcional y Orientado a Objetos).

## Contenido del Repositorio

- **`app.js`**: Contiene la aplicación de los fundamentos del lenguaje (variables, tipos de datos, arreglos, objetos y diferentes tipos de declaraciones de funciones y callbacks).
- **`cal.js`**: Implementa una calculadora demostrando programación funcional (composición, callbacks, promesas y bloque `async/await`).
- **`poo.js`**: Modela una jerarquía de animales para aplicar conceptos de POO (clases, constructores, getters/setters, herencia, polimorfismo, métodos estáticos y el operador `instanceof`).

## Instrucciones de Ejecución

Para correr estos ejemplos, asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu equipo.

Abre una terminal en la raíz de este directorio y ejecuta cada archivo de forma independiente utilizando Node:

```bash
node app.js
node cal.js
node poo.js
